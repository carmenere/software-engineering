# What is Software engineering
**Data Structures and Algorithms** (**DSA**), **System Design** (**SD**) and **Design Patterns** (**DP**) form the three pillars of **software engineering** and **technical interviews**:
- *DSA* focus on how **efficiently** *store data* and *solve computational problems*, **efficiently** means with optimal time and space complexity;
- *Design patterns* provide **reusable solutions** to common software design problems that help developers **write cleaner**, **maintainable**, and **scalable** systems, i.e. they focus on **readability** and **modularity** at the code level;
  - they are traditionally grouped into **3 categories**:
    - **creational** patterns;
    - **structural** patterns;
    - **behavioral** patterns;
- *System design* focuses on architecting **large-scale**, **reliable**, and **distributed** software systems;
